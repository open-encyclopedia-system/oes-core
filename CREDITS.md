## Predecessor Software

This plugin builds on work carried out under a single, continuous DFG-funded
research project, **"Von 1914-1918-online zu dem Open Encyclopedia System"**
(2011–2020), DFG project number
[195110440](https://gepris.dfg.de/gepris/projekt/195110440?language=en).
The project produced two successive software solutions, described below.

**Antragsteller (grant applicants):** Prof. Dr. Nicolas Apostolopoulos,
Dr. Klaus Ceynowa, Prof. Dr. Oliver Janz, Prof. Dr. Miltos Pechlivanos
**Roles (CRediT):** Funding acquisition, Supervision, Project administration

### Phase 1: 1914-1918-online: International Encyclopedia of the First World War, 2011–2015

The conceptual foundations for OES trace back to the project
[“1914-1918-online: International Encyclopedia of the First World
War.”](https://encyclopedia.1914-1918-online.net/)
A custom-built software solution for this project was developed by CeDiS
and was later replaced, in the follow-up phase, by the standardized OES
solution.

**Prof. Oliver Janz** — Project lead
**Roles (CRediT):** Conceptualization, Project administration, Supervision

**Dr. Jennifer Willenberg** — Project coordination
**Roles (CRediT):** Project administration

**Prof. Nicolas Apostolopoulos (PI), Ilker Egilmez** — Software development (CeDiS)
**Roles (CRediT):** Software, Supervision (Apostolopoulos); Software (Egilmez)

### Phase 2: Open Encyclopedia System (OES), 2016–2020

Building on Phase 1, the **Open Encyclopedia System (OES)** was developed as
a standardized platform for creating, publishing, and maintaining scholarly
online encyclopedias in the humanities and social sciences, implemented as
a WordPress plugin with accompanying themes.

Since October 2020, the OES code has been available under a **GPLv2
license** on [GitHub](https://github.com/open-encyclopedia-system/) for use
and extension by third parties.

**Prof. Nicolas Apostolopoulos** — Project lead
**Roles (CRediT):** Project administration, Supervision, Funding acquisition

**Ilker Egilmez** — Implementation of the OES prototype
**Roles (CRediT):** Software
